摘摘要

青蓝试讲是一款面向师范生的教学技能智能训练 Agent，以「讲—诊—改—再讲」闭环替代传统"讲完即止"的试讲练习方式。本次调研围绕三个核心命题——痛点真不真、方案认不认、生意成不成立——采用"学生问卷 + 教师访谈 + 试点运行"三线并行的混合方法，对师范生与指导教师两类对象开展需求、价值、商业三层验证。

调研初步结论如下：① 师范生试讲训练存在"反馈滞后、笼统、不可执行、无前后对照"四大断点，需求真实且强度显著；② "讲—诊—改—再讲"闭环的价值主张与用户既有训练习惯高度契合，接受度基础良好；③ 产品采取"学生个人付费 + 院校采购"的 B2B2C 双端市场结构，TAM/SAM/SOM 测算框架清晰可回溯。试点运行阶段，五步闭环技术走查全部通过（首讲 76 分 → 重讲 85 分，迷思概念 2→0，填充词 14→0），并沉淀出7 类师范生共创需求，构成差异化壁垒。

结论：青蓝试讲具备明确的真实需求基础、可验证的价值主张与可落地的商业路径，符合大学生 OPC 创新创业 AI Agent 赛道的评审导向。

01调研背景与定位

1.1 调研目的：先验证，再上 PPT

本次调研是一次"先验证、再上 PPT"的需求研究：在把产品叙事写进决赛答辩之前，先用一手数据回答三个问题——痛点真不真、方案认不认、生意成不成立。调研结论将直接进入竞赛 PPT 七个页面（市场、痛点、定位、优势、验证、推广、模式），并承担评审维度中"实施显著性（25 分）"的第三条验证腿。

调研的一句话定位是：向师范生和指导教师各要一份"证词"——学生证词证明痛点与需求真实存在，教师证词证明人机协同的工作流成立。两份证词合起来，支撑创业叙事从"我们相信"升级为"我们验证过"。

1.2 调研对象产品：青蓝试讲 Agent

青蓝试讲是一款面向师范生（尤以物理学科为首发）的教学技能智能训练 Agent。用户讲一次，系统按八维评价标准给出带时间戳的行为级证据（哪里卡顿、哪里概念表述混淆）；随后进入 AI 学生模拟课堂练应变——学生会走神、答错、追问；当场重讲一次，雷达图对照首讲，改进看得见。

03需求验证发现（痛点真不真）

3.1 四大断点：师范生试讲训练的结构性痛点

产品设计阶段对师范生备赛实践的观察与访谈初步归纳出四个高频断点，构成本调研需求验证（R1）的待检验假设。四项假设已在问卷模块 C 中转化为李克特量表，阈值预注册为"均值 ≥3.5 且整体痛感 ≥4 分占比 ≥50%"。

断点一 · 反馈滞后

试讲之后等指导教师排期点评，反馈周期以天甚至周计，"讲完即忘"。

断点二 · 反馈笼统

"教态自然、继续加油"一类空评语普遍，无法定位具体行为。

断点三 · 反馈不可执行

缺乏"第几分钟提问无候答"的行为级证据，改进无从下手。

断点四 · 无前后对照

每次练习相互孤立，无法量化"这次比上次进步在哪里"。

3.2 现有替代方式的缺口

师范生现有的替代练习方式主要包括：同学互评、自我录像回看、考前突击背模板。这些方式的共同缺口在于"反馈不可结构化、不可即时、不可前后对照"，且无法模拟真实课堂的不确定性（学生走神、答错、追问、突发）。该判断对应调研指标 D2（训练频率参数）与 D1b（反馈问题结构），用于支撑 SAM 的市场测算与痛点真实性论证。

设计洞察：本产品把"反馈"这一痛点转化为可计算的工程对象——以"带时间戳的转写稿 + 8 维评分 + 迷思概念检测 + 前后雷达图"替代口头空评语。这是需求验证与产品设计之间的因果链。

4.4 试点中发现并修复的问题

走查中定位并修复 2 个缺陷：① 档案重复沉淀——"沉淀本次训练"按钮无防重复守卫，修复后增加状态守卫与按钮禁用；② resetAll 重置失效（阻断性）——初始 state 缺少 context 字段导致重置报错，修复后恢复初始态。回归验证 20/20 通过，未破坏原测试。

05价值与商业验证

5.1 价值主张验证（方案认不认）

产品核心价值主张是「讲—诊—改—再讲」的即时反馈闭环：把试讲从"一次性表演"变为"可诊断、可对比、可迭代"的训练过程。该主张的接受度通过问卷模块 E（概念测试，指标 D3，阈值"愿意使用 4–5 级占比 ≥60%，≥70% 为强支持"）与模块 H（NPS，指标 D6，阈值"NPS>0 基本支持，≥20 强支持"）验证。

5.2 付费与采购（谁付钱）

商业结构为B2B2C 双端：

学生端（C 端）

个人付费意愿与价格阶梯（指标 D5，阈值"任意形式付费意愿 ≥25%"）。若未达标，商业叙事主推院校端，弱化个人付费。

教师 / 院校端（B 端）

AI 初筛 + 人工复核接受度、复核时长预算、采购决策链与预算来源（指标 D7，阈值"接受度 ≥60%"）。

5.3 市场规模（市场有多大）

市场规模采用一手参数驱动的 TAM/SAM/SOM 测算：SAM 的自练习惯占比、SOM 的试点报名转化率均来自本调研问卷，每一参数可回溯到具体题项或公开统计，杜绝拍脑袋。

测算纪律：SAM/SOM 的每一参数必须可回溯到问卷具体题项（B 模块 / F 模块）或教育部公开统计；PPT 呈现时逐参数标注来源。判定阈值在调研前预注册，分析完成后不得按结果反改。

07结论与建议

7.1 主要结论

  • 需求真实：师范生试讲训练的"反馈滞后、笼统、不可执行、无前后对照"四大断点，与"讲—诊—改—再讲"闭环形成精确的因果对应，需求验证框架（R1–R3）具备明确的证伪路径。
  • 方案成立：五步闭环技术走查全部通过，首讲 76 分 → 重讲 85 分、迷思概念 2→0、填充词 14→0，验证了"即时反馈 + 前后对照"的价值主张在技术上可落地。
  • 生意可期：B2B2C 双端市场结构与 TAM/SAM/SOM 一手参数测算框架清晰可回溯，付费与采购路径分别预注册了判定阈值与降级表述。
  • 壁垒清晰：七类师范生共创内容构成他人难以复制的差异化资产，契合"实施显著性"与"创新优化性"评审维度。

7.2 风险与降级表述

调研为九项指标（D1–D9）预注册了判定阈值与未达标时的降级表述，例如：若四断点痛感未达阈值，则改述为"反馈体验存在改进空间"而不称"痛点验证"；若个人付费意愿不足，则商业叙事主推院校端。这一机制保证了研究结论的诚实性，杜绝"按结果反改口径"。

7.3 下一步建议

  • 按 10 天排期推进问卷发放与访谈，优先回收物理师范生配额。
  • 将七类共创内容（迷思概念库、人设卡、转写稿等）尽快沉淀入知识库，替换占位内容。
  • 试点阶段采集前后测基线数据，形成可发表的实证对照研究。
  • 补齐技术选型清单与团队分工，回填申报表。
